# 📋 Employee Management System – Backend (Spring Boot + MySQL) !

This is the **backend service** for the Employee Management System.  
It provides RESTful APIs built with **Spring Boot** and stores employee data in a **MySQL** database.  
The backend communicates with the React frontend to perform **CRUD (Create, Read, Update, Delete)** operations on employee records.

---

## 🚀 Features

✅ Add a new employee  
✅ Update employee details  
✅ Delete employee records  
✅ Fetch all employees  
✅ Search employees by **ID** or **Name**  
✅ Integrated with React frontend  
✅ Connected to **MySQL** database using **Spring Data JPA**  
✅ CORS enabled for cross-origin requests

---

## 🏗️ Tech Stack

| Layer | Technology |
|--------|-------------|
| Backend Framework | Spring Boot |
| Database | MySQL |

| Build Tool | Maven |
